# HearthMesh brand assets

The official HearthMesh identity is the **Beacon Route**: an emergency beacon connected to three resilient network nodes. The beacon represents attributable publishing and a trusted source; the three-node mesh represents replication, alternate paths and continued local access after a failure.

Official tagline: **When Infrastructure Fails, Knowledge Remains.**

## Palette

| Role | Color | Hex |
| --- | --- | --- |
| Beacon signal | Signal orange | `#FFA414` |
| Network nodes | Electric cyan | `#08C7F4` |
| Structural mark | Deep infrastructure blue | `#001B4D` |
| Dark-surface wordmark | Soft near-white | `#E8EFF2` |
| UI base | Near-black blue | `#071015` |

The mark uses flat, solid colors for reliable reproduction in print and at small sizes. The dark UI base is a recommended background color; the standard SVG logos themselves have transparent backgrounds, except the favicon.

## Usage

- Use `logo-horizontal.svg` or `logo-horizontal-dark.png` on dark surfaces; both include the wordmark and official tagline.
- Use `logo-horizontal-print.svg` or `logo-horizontal-light.png` on light surfaces and in documents.
- Use `logo-mark.svg` when a compact symbol is needed on light surfaces.
- Use `profile-github.png` as the ready-to-upload GitHub profile image. It uses the official four-node mark, a light background and safe padding for GitHub's circular crop.
- Use `favicon.svg` for browser/app icon contexts. Its background is built in.
- Use `logo-monochrome.svg` for one-ink printing, engraving, or other single-color output; its ink is `#111820`, so place it on a light substrate.
- Preserve the logo proportions and leave clear space around the symbol at least equal to the diameter of one network node.
- Do not add gradients, shadows, floral elements, extra rays, extra nodes or alternative taglines.

The GitHub profile asset intentionally omits the wordmark and tagline because profile images are displayed at very small sizes. It does not alter the official symbol.

SVG text uses a system sans-serif stack and does not load external fonts or resources.
