01 / PURPOSE

Useful knowledge should not disappear with one service.

HearthMesh helps people and organizations keep selected information accessible during disruption. Each publication carries its source, version and integrity evidence. Participating nodes can retain valid copies without relying on the original publisher.

Continuity, not secrecy.

The public mesh is intentionally attributable. It does not hide publishers, route traffic anonymously or make security claims that the prototype cannot prove.

02 / FLOW

From publication to recovery.

  1. 01Package

    A publisher groups selected files into an immutable HearthPack manifest.

  2. 02Sign

    The publisher signs the manifest with its persistent Ed25519 identity.

  3. 03Replicate

    Configured peers fetch the pack and verify every file before accepting it.

  4. 04Recover

    A damaged copy is rejected and can be restored from a healthy replica.

03 / NETWORK

One protocol, two continuity spaces.

GLOBAL PUBLIC MESH

Shared emergency knowledge

Readable material intended for broad distribution. Every pack is signed, attributable, versioned and subject to each node operator’s replication policy.

  • Public contents
  • Identified publishers
  • Independent replicas
  • Local verification
same node software
PRIVATE CONTINUITY CELL

Restricted operational material

A separate namespace for a family, company or institution. Access control and encryption are planned beyond the first MVP.

  • Known membership
  • Restricted access
  • Explicit publication boundary
  • No anonymous channel

04 / GUARDRAILS

Designed to remain accountable.

01

Attribution

Every public pack identifies the cryptographic key that created it.

02

Direct peers

The official design does not include onion routing or publisher concealment.

03

Readable public layer

The global mesh does not offer anonymous encrypted storage for arbitrary uploads.

04

Operator policy

Each node chooses which publishers and categories it is willing to replicate.
